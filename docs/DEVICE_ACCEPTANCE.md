# Quantumult X 手机验收

本地检查只能验证格式、修改重放、文件与依赖一致性。以下步骤需要安装 Quantumult X 的真实设备完成，当前尚未执行。

1. 备份现有配置、节点和策略选择。确保订阅文件已经发布，使用基础分流配置先测试导入。
2. 添加自己的节点订阅，确认“手动选择”“自动选择”能发现节点，“节点选择”已选可用节点。
3. 刷新远程分流资源，检查所有资源成功加载，无未知策略、解析失败或空资源。检查国内、国外、Apple、OpenAI 和广告请求的命中记录。
4. 选一个真实误拦截条目，在修改清单替换策略，重新构建发布，刷新资源。通过请求记录确认命中修正后的策略，再检查页面实际可用性；两者分别记录。
5. 测试含重写版本。在客户端生成自己的 MITM 证书，安装并信任，确认重写已启用、hostname 含所需域名，脚本 URL 可访问。
6. 对照 blackmatrix7 的 AdvertisingLite、AdvertisingScript 说明及脚本内说明检查客户端和 App 版本。分别测试广告重写与脚本重写，记录功能正常与净化效果；兼容性问题时单独停用相关重写，并保留对应配套分流的测试记录。来源更换不代表手机端效果已经验证。
7. 检查远程资源更新与重新导入完整配置两个流程。重新导入前保存私人节点和本地修改，避免客户端设置被覆盖。

验收记录建议填写：设备、iOS/QX/App 版本、订阅对应 Git 提交、测试请求、实际命中资源与策略、重写执行记录、成功/失败。未完成这些步骤之前，`dist/manifest.json` 的 `device_tested` 保持 false。
